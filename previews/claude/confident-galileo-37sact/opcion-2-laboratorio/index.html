Perfil

Quién soy y cómo trabajo

Me apasiona convertir ideas en productos reales.

Leonera Labs nació como mi espacio para construir: cada app es una excusa para aprender algo nuevo —una arquitectura, un framework, una forma de diseñar— y llevarlo hasta las manos de usuarios reales.

Me importa el código que se puede mantener: pruebas automatizadas, revisiones de código, integración continua y buena documentación. Hoy busco llevar esa forma de trabajar a un equipo grande, con problemas grandes.

// Nota

¿Por qué «Leonera»? Leo, de Leonardo. Y una leonera es el lugar donde viven los leones: mi guarida para construir.

Flujo de trabajo

  1. feat:
    Producto primero

    Entiendo el problema antes de escribir código.

  2. test:
    Calidad medible

    Pruebas, CI/CD y monitoreo desde el día uno.

  3. perf:
    Rápido y accesible

    Apps que cargan rápido y que todos pueden usar.

  4. docs:
    Comunicación clara

    PRs pequeños, documentación y feedback constante.
